# TiPS — Three Idiots Paper Service · 3D Book Showcase

종이 서비스 브랜드 **TiPS (Three Idiots Paper Service)** 를 위한 인터랙티브 3D 북 쇼케이스입니다.
스크롤(휠·트랙패드·터치)로 6권의 책이 무한히 회전·순환하며, 각 권이 브랜드의 서비스를 소개합니다.

## 특징

- **Three.js 기반 3D 씬** — 6권의 책이 스크롤에 따라 회전하며 전환
- **무한 스크롤** — 끝없이 순환 (휠 / 트랙패드 / 터치 / 키보드 ↑↓ 지원)
- **흑백 모노톤** 에디토리얼 디자인 + 종이 질감·그리드 배경
- **단일 HTML 파일** — 표지 이미지를 data URI로 임베드해 추가 파일 없이 동작
- 서비스: Printing · Binding · Bookmaking · Testing · Sampling · Paper Selection
